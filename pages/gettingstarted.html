How to Use My Scripts:

Welcome to the definitive starter guide for modding BULLY: SE on PC using Derpy's Script loader (DSL).

DSL takes away the hassle of older modding methods, letting you run uncompiled .luascripts instantly upon booting the game.

Follow these steps in exact order to prep your game environment safely.


Step One: The Essential Stability Patches:

Before installing your mod loader, you must handle BULLY's famous PC instability.

  • SilentPatch is mandatory, it stops random crashes, fixes the hames memory leaks, and unlocks the frame rate safely.

  • Widescreen Fix adjusts the game engine so HUD elements and camera ratios aren't stretched on modern widescreen aspect ratios.


    • Step Two: Installing Derpy's Script Loader (DSL):

    DSL acts as the backend engine that injects the custom LUA code into the game.

  • Download the Loader: Grab the latest release package of Derpy's Script Loader

  • Extract the Files Open the downloaded .zip archive.

  • Drop the Root: Move the DSL loader files directly into your main BULLY directory (where your Bully.exe resides).

  • Boot the Game Once: Launch BULLY once and you can exit immediately. This forces the loader to generate your local configuration files.

    • Step Three: Where to Put Your Custom Scripts:

    Once DSL is installed, you never have to replace the games original files for scripts again.

  • The Target Folder: Look inside your root folder for a newly generated directory named _derpy_script_loader, and within you will see a folder called scripts.

  • Installing My Scripts: When downloading any of my custom scripts from the Releases section of this wiki, simply drop the uncompiled .lua file (or their specify folder) straight into that /scripts folder. They will execute automatically upon startup.

  • Troubleshooting Advanced Mods: Some scripts require deeper system access permissions. If a script isn't triggering. open /_derpy_script_loader/dslconfig.ini in a text editor, find the line allow_system_access: false, change the value to true, and save.

    • How to Use My Textures (Skins):

    Custom character skins and clothing overhauls live compressed inside the games core asset archive, World.img.

    To install them, chose one of the to methods below.

    Follow these steps in exact order to prep your game environment safely.


    Method A: BULLY Skin Installer by DORKLESS:

    If you want a painless, one-click installation process without messing with archive code, use this automated tool.

  • Get the Tool: Download the BULLY Skin Installer by DORKLESS.

  • Extract the Files Open the downloaded .zip archive.

  • Drop the Root: Move the Skin Installer files directly into your /stream folder in the main BULLY directory.

  • How It Works: You should now see the install.exe along with some other content. Drag and drop the downloaded texture files into the /skin folder and click install".

  • Why Use It: It automatically injects/replaces the .nft/.nif files into the World.img file, so you don't have to manually and/or make mistakes.

    • Method B: Manual Installation Via Archive Editor Tools.

    If you prefer doing things manually or need to resolve specific mod conflicts, you can edit the files directly.

  • Download a Tool Download IMG Tool or IMG Factory 2.0.

  • Locate the Archive Navigate to your main Bully directory, open the stream folder and locate the World.img file.

  • How to Install: Open the World.img inside of your IMG Editor, find the original texture files you want to replace, "ie. the .nif/.nft files", import the new custom texture files, and hit Rebuild/Save.

  • Boot the Game Once: Launch BULLY once and you can exit immediately. This forces the loader to generate your local configuration files.

    • Rule of Thumb for Modding Safely:

     Install One Mod At A Time: Never Drop 10+ scripts into your folder at once. If the game crashes, you won't know which script caused the issue.

    Check Controller Inputs: Some older LUA scripts override default game inputs. If your controls start acting weird, check the scripts page for the remapping details.
